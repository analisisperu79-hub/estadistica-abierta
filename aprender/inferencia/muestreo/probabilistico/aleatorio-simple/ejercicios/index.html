1

Planteamiento del ejemplo

Contexto

Una municipalidad dispone de un padrón de 200 viviendas de un distrito y desea estimar el gasto mensual en agua. Para ilustrar todo el procedimiento, seleccionará un muestreo aleatorio simple sin reemplazo de 10 viviendas.

Datos del problema

  • Tamaño poblacional: \(N=200\)
  • Tamaño muestral: \(n=10\)
  • Variable: gasto mensual en agua (S/)
  • Diseño: MAS sin reemplazo
  • Datos: simulados para enseñanza
Tu tarea como analista

Debes obtener una muestra válida, conservar los identificadores seleccionados y luego usar únicamente esas viviendas para estimar el gasto promedio, su variabilidad y la proporción de viviendas cuyo gasto supera S/ 50.

2

Selección de la muestra, paso a paso

2.1

Definir el marco muestral

El marco debe contener una fila por vivienda y un identificador único.

IDs disponibles 1, 2, 3, 4, 5, …, 200

Comprobar antes: no debe haber IDs duplicados, vacíos ni viviendas fuera de la población objetivo.

2.2

Seleccionar 10 unidades al azar

Usamos selección aleatoria sin reemplazo. En este ejemplo fijamos una semilla para que el proceso pueda reproducirse.

IDs seleccionados

17, 35, 62, 85, 91,
104, 118, 142, 176, 198

2.3

Verificar la selección

  • Hay exactamente 10 identificadores.
  • No se repite ningún ID.
  • Todos están entre 1 y 200.
  • La selección fue sin reemplazo.
  • Cada unidad tiene probabilidad de inclusión \(\pi_i=n/N=0.05\).
Qué debe guardar una persona en un trabajo real

Conserva el archivo del marco original, la fecha de selección, el tamaño \(N\), el tamaño \(n\), la semilla empleada, el software utilizado y el listado final de IDs seleccionados. Eso permite auditar y reproducir la muestra.

Cálculos paso a paso

4.1 Media muestral

Sumamos los 10 gastos y dividimos entre 10:

\[ \bar y=\frac{1}{n}\sum_{i=1}^{n}y_i \]
\[ \bar y=\frac{45+52+38+60+47+55+49+63+41+58}{10}=50.8 \]
Media estimada: S/ 50.80

4.2 Varianza muestral

Usamos la varianza muestral con denominador \(n-1\):

\[ s^2=\frac{1}{n-1}\sum_{i=1}^{n}(y_i-\bar y)^2 \]
Resultado:
\(s^2=68.40\)
\(s=8.27\)

4.3 Varianza y error estándar de la media

Como el MAS es sin reemplazo, aplicamos la corrección por población finita:

\[ \widehat{\mathrm{Var}}(\bar y) = \left(1-\frac{n}{N}\right)\frac{s^2}{n} \]
\[ \left(1-\frac{10}{200}\right)\frac{68.40}{10}=6.498 \]
\[ SE(\bar y)=\sqrt{6.498}=2.55 \]

4.4 Proporción de viviendas con gasto > S/ 50

Hay 5 viviendas de 10 por encima de S/ 50:

\[ \hat p=\frac{x}{n}=\frac{5}{10}=0.50 \]
Proporción estimada: 50%

4.5 Intervalo de confianza para la media

Como ejemplo didáctico usamos la aproximación normal:

\[ \bar y\pm1.96\,SE(\bar y) \]
\[ 50.8\pm1.96(2.55) \]
IC 95% aproximado: [45.80, 55.80] soles.
5

Resultados e interpretación

1

Media

La muestra estima que una vivienda del distrito gasta en promedio S/ 50.80 al mes en agua.

2

Variabilidad

La desviación estándar de S/ 8.27 resume cuánto varían los gastos individuales alrededor de la media muestral.

3

Precisión

El error estándar de S/ 2.55 cuantifica la variabilidad esperada de la media muestral bajo este diseño.

4

Proporción

En la muestra, 50% de las viviendas gasta más de S/ 50 mensuales.

Importante

Los valores de este caso son simulados para enseñar el procedimiento. No representan estimaciones reales de un distrito ni deben citarse como estadísticas oficiales.

Cómo hacerlo en R y Python

RSelección reproducible
set.seed(123)

N <- 200
n <- 10

ids <- 1:N

muestra_ids <- sample(
  ids,
  size = n,
  replace = FALSE
)

muestra_ids
PythonSelección reproducible
import numpy as np

rng = np.random.default_rng(123)

N = 200
n = 10

ids = np.arange(1, N + 1)

muestra_ids = rng.choice(
    ids,
    size=n,
    replace=False
)

print(muestra_ids)

Después del sorteo

  1. Guarda los IDs seleccionados.
  2. Filtra la base original usando esos IDs.
  3. Comprueba que obtuviste exactamente \(n\) filas.
  4. Analiza únicamente las observaciones seleccionadas.
  5. Conserva la semilla para poder reproducir el sorteo.
